# GreenBox I18n project files

This folder was created automatically by GreenBox I18n.

- `localization.json` is the editable localization source. Prefer the GreenBox Web Editor or CLI.
- `localization.asset` is managed by GreenBox I18n. Do not edit, replace, or recreate it manually.
- You may move or rename this folder and its files. Prefer doing so inside Unity.
- Keep the accompanying `.meta` files and commit them to version control.
- If you edit the JSON manually, preserve existing entry IDs and validate the result.
